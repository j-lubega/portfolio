# Brand icons

Brand glyphs come from the `simple-icons` set through `astro-icon`, bundled from the allowlist in
`astro.config.mjs`. They appear only as "works with" indicators next to a technology name (stack
tags, capability rows, the hero topology), never as endorsements, never recolored into the site
accent, and never resized below 14 px. Each mark belongs to its owner; the notes below record the
guideline consulted and the constraint that applies.

| Glyph                                          | Owner                                | Usage note                                                                                   |
| ---------------------------------------------- | ------------------------------------ | -------------------------------------------------------------------------------------------- |
| `simple-icons:amazonwebservices`               | Amazon Web Services                  | Referential use next to the AWS name only; do not imply partnership or certification status. |
| `simple-icons:kubernetes`                      | The Linux Foundation (CNCF)          | Logo may be used to refer to the project; not to suggest CNCF endorsement.                   |
| `simple-icons:terraform`                       | HashiCorp (IBM)                      | Referential use; keep the mark unaltered.                                                    |
| `simple-icons:ansible`                         | Red Hat                              | Referential use; keep the mark unaltered.                                                    |
| `simple-icons:linux`                           | Larry Ewing (Tux)                    | Freely usable with attribution to the artist in this file.                                   |
| `simple-icons:docker`                          | Docker, Inc.                         | Referential use next to the Docker name.                                                     |
| `simple-icons:githubactions`                   | GitHub                               | Referential use; do not combine with other marks.                                            |
| `simple-icons:prometheus`                      | The Linux Foundation (CNCF)          | As Kubernetes.                                                                               |
| `simple-icons:grafana`                         | Grafana Labs                         | Referential use; keep the mark unaltered.                                                    |
| `simple-icons:posit`                           | Posit Software, PBC                  | Referential use; the client's own work relates to Posit products.                            |

as text with a generic cloud glyph from `lucide`.
